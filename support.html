Common questions

  • The scan read the wrong dose. Fix it on the review screen before saving; the highlighted fields are the ones the scan was unsure about. If a label keeps misreading, email us a description of it (not a photo).
  • Reminders aren't firing. Settings → Notifications → Glyph must be allowed. Profile in the app shows how many reminders are set.
  • A caregiver can't see a pet. Invite codes expire after seven days and work once. Generate a new one from Profile → Household.
  • I want my data gone. Profile → Delete account. It is immediate.
